# Ключевые особенности и ограничения.
### 1. Совместимость с конкретной сборкой CEF
Код работает только с `cef.dll` / `cef.so` из репозитория - в этих билдах присутствует какой-то фикс (не помню какой, по моему его делал Cheaterman). Недавно [samp-cef](https://github.com/zottce/samp-cef) обновился, возможно, фикс уже включён, но официального релиза пока нет — требуется ручная сборка.

### 2. Сериализация данных в JSON
Из-за особенностей [samp-cef](https://github.com/zottce/samp-cef) все данные передаваемые в события упаковываются в JSON строку и передаются одним аргументом.
* На стороне Python используется `json.dumps` / `json.loads`.
* Ожидается что данные всегда являются строкой, которая содержит словарь (Python `dict` или TypeScript `Record<any, any>`).

### 3. Browser ID `==` Player ID
Использование нескольких браузеров на одного игрока [не рекомендуется](https://github.com/zottce/samp-cef/blob/refresh-code/docs/main_ru.md#%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B-%D0%BF%D0%BE-%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8E-%D0%B8-%D0%BD%D0%B5%D0%BA%D0%BE%D1%82%D0%BE%D1%80%D1%8B%D0%B5-%D0%BE%D0%B3%D1%80%D0%B0%D0%BD%D0%B8%D1%87%D0%B5%D0%BD%D0%B8%D1%8F), поэтому я принял такое решение, и на данный момент не вижу причин это менять.


# Процесс инициализации
1. `Player.on_connect` -> `Browser.init_cef` (инициализация CEF для игрока)
2. `Browser.on_cef_init` -> `Browser.create`
3. `Browser.on_created` -> браузер создан, но это не значит что страница сайта загружена
4. `Browser.on("cef::dom::ready")` -> браузер полностью готов к работе (это событие вы реализовываете сами)


# Планы по хешированию имён событий
Я не уверен, но возможно в CEF есть ограничение на длину имени события, либо длинные имена будут создавать избыточную нагрузку.

Поэтому возможно стоит реализовать механизм хеширования `{"event:name": "b563b034d07", ...}`, а затем механизм рукопожатия, когда при подключении игрока клиент и сервер обмениваются "картами событий".

У меня недостаточно опыта в TypeScript (на клиенте) поэтому я не стал реализовывать это, по крайней мере пока.
